# Iris Flower Classification 🌸

A simple Machine Learning project that classifies Iris flower species using the famous Iris dataset.

## Species Predicted
- Setosa
- Versicolor
- Virginica

## Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy

## Project Structure
```
iris_ml_project/
│
├── train_model.py        # Train the ML model
├── predict.py            # Predict species from user input
├── requirements.txt      # Project dependencies
└── README.md             # Project documentation
```

## Installation

1. Clone the repository

```
git clone https://github.com/yourusername/iris-ml-project.git
cd iris-ml-project
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Train the model

```
python train_model.py
```

4. Run prediction

```
python predict.py
```

## Example Input

Sepal Length: 5.1  
Sepal Width: 3.5  
Petal Length: 1.4  
Petal Width: 0.2  

Output:
```
Predicted Species: Setosa
```

## Dataset
Uses the built‑in Iris dataset from Scikit‑learn.
